## ¿Para qué sirven los Controllers?

En Laravel, los *controllers* (controladores) reciben las solicitudes HTTP y coordinan la respuesta de la aplicación. Conectan las rutas con la lógica necesaria para atender cada solicitud.

En una API, un controlador puede validar los datos recibidos, consultar o modificar información mediante modelos o servicios y devolver una respuesta, normalmente en formato JSON y con el código HTTP correspondiente.

Las rutas indican qué método del controlador debe ejecutarse para cada endpoint. Así, la lógica queda organizada y separada de la definición de las rutas.
